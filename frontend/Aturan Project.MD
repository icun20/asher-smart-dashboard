# Aturan Project
- Stack: Next.js (App Router) + Tailwind CSS
- Konten website: Bahasa Inggris. Nama file & variabel: Inggris.
- Mobile-first. Selalu cek tampilan di lebar 375px, 768px, 1280px.
- Komponen reusable di /components, satu file satu komponen.
- Jangan install library baru tanpa izin gua.
- Jangan ubah file di luar yang diminta.
- Jangan taruh API key/secret di kode. Pakai .env.
- Kalau ada yang ambigu, tanya dulu, jangan asumsi.
- Setelah selesai, jelasin singkat file apa yang diubah, pakai bahasa awam.
